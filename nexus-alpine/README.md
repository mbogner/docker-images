# Nexus Alpine

Sonatype Nexus on top of Alpine Linux with multiplatform support.

## Start a container

```shell
#!/usr/bin/env bash
docker run -ti --rm --name nexus \
  -p 127.0.0.1:8081:8081 \
  -v ./nexus.secrets.json:/home/application/nexus.secrets.json:ro \
  mbopm/nexus-alpine:latest
```

Make sure to have a proper nexus.secrets.json mounted.

Sample file:

```json
{
  "active": "sample",
  "keys": [
    {
      "id": "sample",
      "key": "your_key_here"
    }
  ]
}
```
A key can be generated by running:

```shell
openssl rand -base64 32
```

## Print default password

Assumed your container has the name `nexus`:

```shell
#!/usr/bin/env bash
docker exec -ti nexus cat sonatype-work/nexus3/admin.password
```
